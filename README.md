
# Интернет-магазин на Django
Проект интернет-магазина, создаваемый в рамках учебного курса по Python/Django. Данный проект позволяет приобрести практические навыки работы с фреймворком Django, начиная от базовых настроек проекта и заканчивая разработкой функциональности сайта.

#### Требования и зависимости
Зависимости проекта находятся в файле requirements.txt. Для установки всех зависимостей выполните команду:
```
pip install -r requirements.txt
```

Приступите к разработке:

```python manage.py runserver```

Теперь вы можете просматривать сайт, перейдя по адресу http://localhost:8000/.

#### Функционал проекта

- Контроллеры:
   Главная страница (/): отображается главная страница магазина.
    Страница контактов (/contacts/): форма обратной связи и контактные данные.
- Шаблоны:
    Используются HTML-шаблоны с поддержкой Bootstrap для удобной стилизации.
#### Правила разработки

Используется методология Git Flow для управления версиями проекта. Существуют три основных ветви:
- main: стабильная версия проекта.
- develop: рабочая ветвь для интеграции новых функций.
- тдельные ветки для каждой домашней работы перед слиянием в develop.
#### Подключение URL-адресов
В проекте используется механизм разделения маршрутов с использованием include(), чтобы поддерживать четкую организацию ссылок.
